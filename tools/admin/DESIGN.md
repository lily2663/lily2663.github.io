# LilyMap Studio

面向个人写作者的编辑工作室，延续 lily-epitaph 的薄荷绿、粉色与亚克力材质。固定的柔和色晕背景透过半透明面板，配合边缘高光、低强度阴影与背景模糊建立层次；不叠加动态壁纸。首页的书页与枝叶 SVG 呼应写作和内容生长，跟随明暗主题切换，不依赖外部图片或字体服务。

- `public/css/studio.css`：最终视觉令牌、导航、列表、按钮、首页和响应式样式；功能页面的布局仍由 `workspace.css` 管理。
- `public/js/core/icons.js`：统一 24px 线性图标，装饰图标不重复参与屏幕阅读器朗读。
- `public/js/core/studio.js`：首页展示，数据由既有状态传入，动作沿用 `app.js` 绑定。
- 首页先展示导入入口，再展示真实内容数、草稿数、更改数和预览运行状态，最后提供文章列表和设备预览。
- 浅色：`#edf3f2` 背景、白色磨砂表面、`#2c3e50` 正文、`#39776f` 操作色。
- 深色：`#182329` 背景、蓝灰磨砂表面、`#e8f1f1` 正文、`#9ad5cb` 操作色。
- 模糊仅用于面板级别，列表每一行不单独模糊；不支持 backdrop-filter 的浏览器回退到不透明面板。输入区保留更高不透明度。
- 首页装饰区控制高度，让常用操作和文章列表更早进入视线。列表标题允许换行，窄屏将日期放到标题下方、状态保留在右侧。
- 800px 以下改为顶部横向导航；540px 以下首页统计采用两列，快捷操作采用单列。
- 按钮保留键盘焦点轮廓，输入框提供明确聚焦状态；减少动态效果偏好下禁用快捷卡片位移。

视觉改动后需要同时检查浅色、深色、桌面和窄屏；新增浏览器资源也要加入 `server.mjs` 的源码导出清单，重新打包后才会进入 EXE。

模块库延续同一组亚克力令牌：所有模块使用平级卡片，搜索和使用状态筛选可以组合。详情将使用位置与参数表单分栏，窄屏改为单列。音乐的显示参数、共享歌单使用两个可键盘切换的页签；切换仅隐藏面板，不销毁未保存的输入。保存状态明确区分未修改、待保存、保存中、成功和失败。
