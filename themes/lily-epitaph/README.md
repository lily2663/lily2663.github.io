# lily-epitaph

`lily-epitaph` is an opinionated Hugo theme for technical writing. It keeps the watercolor welcome scene, the draggable pet, long-form reading layout, code-copy controls, client-side search, RSS, sitemap and optional protected-content support while remaining a static Hugo site.

## Install

Copy or add this directory as `themes/lily-epitaph`, then set the theme in the site configuration:

```toml
theme = "lily-epitaph"
```

Run the bundled example with Hugo 0.165.0 or newer:

```powershell
Set-Location themes/lily-epitaph/exampleSite
hugo server --themesDir ../..
```

For a normal site, add Markdown below `content/posts/` and run `hugo server` or `hugo --minify`.

## Minimal configuration

```toml
baseURL = "https://example.com/"
locale = "zh-cn"
title = "My Notes"
theme = "lily-epitaph"

[params]
  subtitle = "notes and experiments"
  description = "A personal technical blog"
  author = "Author"
  avatar = "/avatar.jpg"

[params.welcome]
  enabled = true
  # Omit background to use the theme's bundled watercolor image.
  # background = "/assets/my-watercolor.jpg"
  titleBefore = "Welcome to "
  accent = "My"
  titleAfter = " Notes"
  subtitle = "notes and experiments"
  enterText = "Enter"
  hint = "Press any key or click to enter"
  particles = 30

[params.pet]
  enabled = true
  # Omit image to use /lily-epitaph/tuanzi.png.
  # image = "/assets/my-pet.png"

[params.search]
  enabled = true

[params.protected]
  enabled = false

[params.comments]
  enabled = false
  # api = "https://comments.example.com"

[params.github]
  # username = "octocat"

[params.footer]
  copyright = "Built with Hugo"
  note = "Markdown-first publishing."

[[menus.main]]
  name = "Home"
  url = "/"
  weight = 10
[[menus.main]]
  name = "Tags"
  url = "/tags/"
  weight = 20
```

The bundled defaults are intentionally stylistic. Site configuration owns the title, navigation, welcome wording, asset overrides, comment endpoint, GitHub account and footer copy; the theme owns presentation and behavior.

## Content

Create a post in `content/posts/my-post/index.md`:

````md
---
title: My post
date: 2026-01-01
summary: A concise description used by cards and social metadata.
tags: [Hugo, Notes]
---

## A heading

```go
fmt.Println("code blocks get a copy button")
```
````

Images can use page bundles or root-relative site assets. Article images are lazy-loaded and open in a lightbox.

## Search and keyboard controls

Search is enabled from `params.search.enabled`. Article mode matches title, summary and tags. Text mode lazily requests `/index.json` only when needed. `/` focuses search, `Escape` clears it, and `ArrowDown` moves to the first visible result.

## Optional protected content

Set `params.protected.enabled = true`, then mark a post with `protected = true` and provide a payload generated by the site-level protection workflow. The theme contains no passwords, plaintext or site-specific encrypted content. Successful unlocks reuse the normal article body, TOC and code-copy behavior.

## Optional integrations

Comments load only when both `params.comments.enabled` and `params.comments.api` are configured. GitHub statistics load only on the About page when `params.github.username` is configured. Neither integration is required for the theme to build.

## Theme assets

The theme ships default welcome and pet assets below `static/lily-epitaph/`. A site may override them through the welcome background and pet image parameters; no project-relative paths are required.

## Production build

```powershell
hugo --gc --minify
```

The site output is static. Hugo generates canonical URLs, RSS, sitemap, robots.txt and article metadata from the site configuration and front matter.
